# 🎨 Telegram Prompt Architect v2.0 (Advanced Multimodal)

> Просунута, високонавантажена версія Telegram-бота, розширена до мультимодального конвеєра, який паралельно генерує текстовий промпт, створює для нього унікальне зображення та синтезує голосову озвучку результату.

## 📋 Опис архітектури

Версія 2.0 успадковує систему маршрутизації та STT з першої версії, але кардинально змінює етап обробки та дистрибуції контенту. AI-агент навчається повертати відповідь виключно у суворому форматі JSON, що містить як текстову частину, так і окремий промпт для генерації картинок. Після цього n8n розгалужує потік на паралельні асинхронні запити до різних API, синхронізує бінарні потоки та відправляє медіа-бандл користувачу.

## 🛠 Специфікація воркфлоу та ключові ноди

1. **JSON Промптинг та Санітаризація:** Системний промпт ШІ-агента змушує його повертати об'єкт із полями `text_response` та `image_prompt`. Нода `Parse: Extract LLM JSON` (Code node) очищає відповідь моделі від можливих Markdown-літералів (наприклад, ` ```json `) та безпечно парсить об'єкт, страхуючи систему від crash-падінь.
2. **Паралельна генерація активів:**
   * **Гілка Зображень:** Нода `[API] Generate Image Asset` робить HTTP POST запит до OpenRouter на модель `black-forest-labs/flux.2-klein-4b` для створення креативного візуалу за промптом. Кастомний JS-скрипт декодує отриманий Base64-буфер у файл `generated_image.png`.
   * **Гілка Аудіо (TTS):** Нода `[TTS] Generate Audio Media` паралельно відправляє згенерований текст в OpenAI Text-to-Speech (модель голосу `onyx`) для генерації звукової доріжки.
3. **Асинхронний Мердж:** Нода `Merge: Sync Media Streams` працює в режимі `combineByPosition`. Вона утримує виконання, поки обидва бінарні потоки (картинка та аудіо) не завершать генерацію, об'єднуючи їх в один вихідний payload.
4. **Трансформація корисного навантаження:** Нода `Transform: Prepare Output Payload` філігранно перепаковує бінарні ключі в структуру, яку очікує Telegram Bot API, перейменовуючи їх у `image_data` та `audio_data`.
5. **Мультимодальний Dispatch:** Бот відправляє користувачу три взаємопов'язані повідомлення: красивий HTML-текст промту, згенероване зображення високої якості та аудіофайл із професійною озвучкою.

## 🛠 Стек технологій

* **Оркестрація:** n8n (Advanced Parallel Execution, Binary Data Manipulation, Merge Synchronization)
* **Штучний Інтелект:** OpenRouter (`openai/o4-mini` для тексту, `black-forest-labs/flux.2-klein-4b` для зображень), OpenAI API (`Whisper` для STT, `TTS onyx` для аудіосинтезу)
* **Платформа:** Telegram Bot API (Multimodal methods: `sendPhoto`, `sendAudio`, `sendMessage`)

## ⚙️ Інструкція з розгортання

1. Імпортуйте файл `Telegram_promt_bot(Text+Image+Audio).json` у ваш інстанс n8n.
2. Переконайтеся, що ваші API-ключі мають доступ до моделей генерації зображень Flux на OpenRouter та OpenAI TTS.
3. У нодах Telegram перевірте, чи активована опція `Continue Regular Output` у розділі `On Error` (це гарантує, що якщо, наприклад, впаде TTS, користувач все одно отримає текст та картинку).
4. Активуйте воркфлоу.
