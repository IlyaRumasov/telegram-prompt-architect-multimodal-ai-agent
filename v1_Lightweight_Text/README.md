# 🤖 Telegram Prompt Architect v1.0 (Text-Only MVP)

> Перша версія (MVP) кастомного Telegram-бота на базі n8n для автоматизованого перетворення сирих ідей користувачів у структуровані, професійні текстові промпти (мета-інженерія).

## 📋 Опис архітектури

Ця версія фокусується на побудові стабільного ядра обробки текстових та голосових команд. Воркфлоу реалізує подієво-орієнтовану (Event-Driven) логіку: бот приймає повідомлення через вебхуки, розподіляє їх за типами та командами за допомогою умовного роутера, трансформує голос у текст та віддає запит інтелектуальному агенту з пам'яттю.

## 🛠 Специфікація воркфлоу та ключові ноди

1. **Диспетчеризація (Routing):** Нода `Route: Dispatch Command Flow` (Switch) аналізує вхідний текст або callback-дати для точного розподілу потоку на сервісні команди (`/start`, `/help`, `/donate`) або бізнес-запити (фідбек, співпраця).
2. **Транскрибація голосу (STT):** Якщо користувач надсилає голосове повідомлення, нода `[TG] Fetch Voice Asset` завантажує бінарний файл за його ID, а нода `[STT] Transcribe Voice Media` (інтеграція з OpenAI Whisper) перетворює аудіо в чистий текст.
3. **Оркестрація ШІ-агента:** Нода `[AI] Orchestrate Prompt Agent` використовує модель `openai/o4-mini` (через OpenRouter) зі строгим системним промптом (System Message), який змушує модель діяти як мета-інженер. Агент повертає чітко структурований текст за методологією: Persona, Context, Task, Constraints, Format.
4. **Керування контекстом:** Нода `[Mem] Load Context Buffer` (Window Buffer Memory) прив'язана до `chat_id` Telegram та зберігає до 10 останніх реплік для ведення повноцінного діалогу.
5. **Аудит і логування:** Усі успішні запити паралельно записуються у внутрішню базу даних через ноду `[DB] Append Audit Record` (n8n Data Tables) для збереження історії використання (`user_id`, `first_name`, `text`, `username`).

## 🛠 Стек технологій

* **Оркестрація:** n8n (Switch Routing, Data Tables, Whisper Integration)
* **Штучний Інтелект:** OpenRouter (`openai/o4-mini`), OpenAI (`Whisper` для STT)
* **Платформа:** Telegram Bot API (Webhook Mode)

## ⚙️ Інструкція з розгортання

1. Імпортуйте файл `Telegram_promt_bot.json` у ваш інстанс n8n.
2. Налаштуйте Credentials для `Telegram API`, `OpenRouter API` та `OpenAI API`.
3. Створіть внутрішню n8n Data Table з назвою `Telegram Bot Users Log` або перевиберіть власну базу даних у ноді логування.
4. Активуйте воркфлоу.
